## Method

- **scan** is what an agent can do without an inverted index: a whole-word, case-insensitive regex per query word on the base table, restricted to the slice by `ts`. The `@@` operator needs an inverted index, so there is no index-free full-text predicate to compare with.
- **full index** is the Dataset's canonical inverted index with the slice as a `ts` range.
- **agent index** is the partial inverted index `create_index` built (`CREATE INDEX … USING inverted (…) WHERE ts >= … AND ts < …`), resolved through `corpus.datasets.relation()` for a Data Scope inside the slice.
- All three modes returned identical rows for every query on every run (checked).
- Measurements are interleaved (each run times every query in every mode), so a load change on the shared server affects all modes alike. Break-even uses the median build time and the mean of the per-query medians.
